# Controller V0.1 架构图

> 按 Share 中最终确认的 draw.io 设计：输入后先查询扩写，再并行执行 **KB 检索** 与 **LLM 检索**，每个检索链路都包含“上下文思考”，最后按 KB score × LLM prob 四象限分类路由。

## 2. 检索链路细节

### KB 检索链路

```
用户 query
    │
    ▼
查询扩写（QueryExpander）
    │
    ├─► 向量 + 关键词 查询
    ├─► 重排序查询
    ├─► 查询扩展（同义/补全）
    └─► 上下文思考（结合短期记忆）
            │
            ▼
    KB 向量检索（BGE-M3 + BM25 + rerank）
            │
            ▼
    KB 检索结果（score）
```

### LLM 检索链路

```
用户 query
    │
    ▼
Hybrid + Expanded 查询生成
    │
    ▼
上下文思考（结合短期记忆）
    │
    ▼
SVM-Linear 分类器
    │
    ▼
LLM 检测结果（known probability）
```

## 3. 四象限分类规则

| 情况 | KB 分数 | LLM known 概率 | 处理路径 | source |
|---|---|---|---|---|
| **A** | ≥ KB_HIT_HIGH (0.6) | ≥ LLM_KNOWN_HIGH (0.7) | 直接 RAG 生成 | `kb` |
| **B** | ≥ KB_HIT_HIGH (0.6) | < LLM_KNOWN_HIGH (0.7) | 依 KB 逻辑推理 + 多路影子验证 + frozen LoRA 后训练 | `kb_reasoned` |
| **C** | < KB_HIT_HIGH (0.6) | ≥ LLM_KNOWN_HIGH (0.7) | MoE 多路推理 + 网查对比 + 验证合理后写入 KB | `llm_moe` |
| **D** | < KB_HIT_HIGH (0.6) | < LLM_KNOWN_HIGH (0.7) | 联网搜索摘要补充进 KB，然后进入 B 流程整理学习 | `unknown` |

## 4. 模块职责

| 模块 | 文件 | 职责 |
|---|---|---|
| 短期记忆 | `context_memory.py` | 保存最近 N 轮对话，支持上下文改写与指代消解 |
| 查询扩写 | `query_expander.py` | 结合上下文生成同义/补全查询变体 |
| KB 客户端 | `kb_client.py` | `/v1/search` 检索、`/v1/add_snippets` 回写 |
| LLM 知识检测 | `classifier.py` | 封装 `predict_llm_detector`（Hybrid + Expanded + SVM-Linear） |
| 联网搜索 | `web_search.py` | `ddgs` 搜索，失败降级 |
| LLM 客户端 | `llm_client.py` | RAG、RAG推理、MoE、验证、未知、学习日志 |
| 路由决策 | `controller.py` | 四象限分类与分支调度 |
| CLI 入口 | `main.py` | 命令行与 JSON 输出，支持交互模式 |

## 5. 三种记忆

| 记忆类型 | 对应模块 | 说明 |
|---|---|---|
| **短期记忆** | `ContextMemory` | 当前对话上下文，用于指代消解和意图补全 |
| **长期显式记忆** | KB（Chroma + BGE-M3 + BM25） | 可检索、可回写、可解释的知识库 |
| **长期隐式记忆** | LLM 内部权重 | 黑箱式参数记忆，通过检测器评估置信度 |

## 6. 与外部系统的接口

### 本地大模型（llama.cpp）

- 地址：`http://127.0.0.1:8080`
- 用途：
  - LLM 检测器生成短答案/展开说明（`/completion`）
  - Controller 最终回答生成（`/v1/chat/completions`）
  - 语义相似度（`/embeddings`）

### 本地知识库

- 地址：`http://127.0.0.1:7861`
- 端点：
  - `POST /v1/search`：返回带 `score` 的 chunks
  - `POST /v1/add_snippets`：接收 `{source, content}` 写入 KB

### 联网搜索

- 库：`ddgs`（DuckDuckGo）
- 无需 API Key

## 8. 可扩展点

1. **短期记忆**：当前仅文本队列，后续可加入摘要、实体追踪、情感状态；
2. **查询扩写**：可接入同义词库、领域词典、查询理解模型；
3. **LLM 检测**：可从 2 分类扩展为 known/open/unknown 3 分类；
4. **验证层**：MoE 验证目前用联网搜索，后续可接入多模型投票、置信度校准；
5. **学习闭环**：B 的影子验证和 D 的补充 KB 当前记录日志/写入 KB，真正 frozen LoRA 需后续训练管线接入。
