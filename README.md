# 知道不知道 · Knowing Limits

> 《知道不知道：生成式 AI 认知边界披露对人机信任校准与决策质量的影响》

一个用「AI 知道不知道」来治理信任的研究：AI 在认知边界内正常作答、在边界外按治理策略披露（推理披露 / 干净拒答 / 硬答），测量这些策略如何改变人机信任校准与决策质量。论文的行为实验由 Synbasin 认知操作系统的四象限路由真实分流驱动——**治理版条件 = 平台的真实 C/D 分流**。

---

## 工程实现：Synbasin 四象限路由

平台是认知操作系统的「调度中心」。核心思想：**不靠单一 LLM 判断「我知不知道」，而是用两条独立链路交叉定位认知边界**。

### 核心架构

```
用户问题
   │
   ▼
短期记忆（ContextMemory）→ 查询扩写（QueryExpander）
   │
   ├──────────────┬──────────────┐
   ▼              ▼
KB 检索         LLM 知识检测
（长期显式记忆）   （长期隐式记忆）
BGE-M3+BM25     Hybrid+SVM-Linear
+rerank          → known 概率
   │              │
   └──────┬───────┘
          ▼
   四象限分类器（KB score × LLM prob）
          │
   ┌──────┼──────┬──────┐
   ▼      ▼      ▼      ▼
   A      B      C      D
```

### 四象限分流

| 象限 | KB 分数 | LLM known | 处理路径 |
|---|---|---|---|
| **A** | ≥0.6 | ≥0.7 | 直接 RAG 生成（知识库内，带引用） |
| **B** | ≥0.6 | <0.7 | 依 KB 逻辑推理 + 多路影子验证 + frozen LoRA |
| **C** | <0.6 | ≥0.7 | MoE 多路推理 + 联网对比 + 验证后回写 KB |
| **D** | <0.6 | <0.7 | 联网补 KB → 转 B 流程（学习） |

### 三层记忆

| 记忆 | 模块 | 说明 |
|---|---|---|
| 短期 | `ContextMemory` | 当前对话上下文（指代消解、意图补全） |
| 长期显式 | KB（Chroma + BGE-M3 + BM25） | 可检索、可回写、可解释 |
| 长期隐式 | LLM 权重 | 黑箱参数记忆，由检测器评估置信度 |

### 三个组件

- **`controller/`** — 四象限路由调度中心（1.3M，含 `ARCHITECTURE.md` 架构图与设计文档）
- **`cos/`** — 可复用认知操作系统框架（三层记忆 + 双模式：本地 LLM / 远程 API）
- **`knowledge-base/`** — 本地知识库（Gradio + Chroma + BGE-M3 + GLM-4.5-Air）

## 论文与平台的关系

论文四条件（组间）：**硬答 / 拒答 / 拒答+指引 / 治理版**。

其中「治理版」是唯一用**真实平台分流**的条件：

- 边界内题 → 平台走 **A 象限**（KB 检索带引用，正常作答）
- 边界外 C 型题（LLM 知道但 KB 没有）→ 平台走 **C 象限** → 实验包装为「**推理披露**」（声明缺数据 + 行业推理 + 结论）
- 边界外 D 型题（两者都不知道）→ 平台走 **D 象限** → 实验包装为「**干净拒答**」

其余三个条件是「无治理裸 LLM」或「二元边界治理」，作为对照臂。**论文测的是「披露策略」的信任价值，平台提供的是「真实分流」而不是实验者手动指定。**

## 复现

### 平台部署（模型需自行准备）

底座 LLM 是 **GLM-4.5-Air**（Q5_K_M，约 78GB），经 llama.cpp 以 OpenAI 兼容接口暴露于 `:8080`。**本仓库不含模型权重与 llama.cpp**，需自行部署：

1. 部署 llama.cpp + GLM-4.5-Air（或用任意 OpenAI 兼容端点，改 `cos` 环境变量即可）
2. 启动 KB：`cd 平台/knowledge-base && pip install -r requirements.txt && python app.py`（默认 `:7860`）
3. 配置 `cos`：`COS_MODE=remote`（外部 API）或 `local`（本地 LLM）
4. 调用：`from cos import Controller; Controller(...).process("...")`

详见 `平台/controller/ARCHITECTURE.md`、`平台/cos/README.md`、`平台/knowledge-base/README.md`。

### 实验复现

1. 计算实验：`python 03_架构与代码/sim_study1_v2.py` → `02_数据/sim_results_v2.csv`
2. 行为实验分析：`python 03_架构与代码/analyze_study2.py`
3. 问卷文件再生成：`python 03_架构与代码/gen_wjx.py`
